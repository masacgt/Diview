## 🔖 アプリ画面開発指示書：配当管理アプリ
あなたは優秀なUI/UXデザイナーおよびフロントエンドエンジニアです。
以下の仕様と画面概要に基づき、証券口座連携が不要で、ユーザーが手動で銘柄を登録して配当金を可視化できる「配当管理アプリ」の画面を構築してください。
------------------------------
## 🏗️ 共通仕様・デザインシステム

* デザイン言語: クリーン、高信頼性、直感的。ダークモードとライトモードの両方に対応。
* カラーパレット:
* メインカラー：信頼感のあるネイビー、または資産成長をイメージさせるエメラルドグリーン
   * アクセントカラー：プラス損益（緑/青）、マイナス損益（赤）
* ナビゲーション: 画面下部に常駐する「ボトムナビゲーションバー」を採用。
* タブ構成：①資産管理 / ②年間配当 / ③月別グラフ / ④設定

------------------------------
##  各画面の詳細概要

資産管理画面（ホーム・一覧）ユーザーが保有している銘柄の評価額と損益を一覧で確認する画面です。ヘッダーエリア（総資産サマリー）:現在の「総資産評価額」を大きく表示。「トータル含み損益（額・％）」を表示（プラスなら青/緑、マイナスなら赤）。フィルター・ソート機能:市場切り替えタブ：「すべて」「日本株」「米国株」「投資信託」ソートボタン：「評価額順」「利回り順」「年利順」などで並び替え可能。銘柄リスト（スクロールエリア）:各行（カード型）の表示項目：銘柄コード / ティッカー銘柄名保有株数（口数）現在株価（自動取得想定）評価額（株価 × 株数）銘柄ごとの損益投資枠バッジ（「新NISA 成長枠」「新NISA つみたて枠」「特定口座」などを視覚的に分類）アクションボタン:画面右下に浮かぶ「＋（フローティングアクションボタン）」を配置。タップすると「銘柄登録モーダル」が開く。

------------------------------
##   年間配当額画面（円グラフ・資産構成）銘柄ごとの年間配当額の比率や、ポートフォリオのセクター分布を視覚化する画面です。ヘッダーエリア:「年間想定配当金（総額）」を大きく表示。「平均予想配当利回り（％）」を表示（評価額基準 / 取得額基準の切り替えスイッチ付き）。ビジュアル表示エリア（切り替え式）:円グラフタブ: 銘柄ごとの年間配当金額のシェアを表示。割合が小さい銘柄は自動で「その他」にまとめる。ツリーマップタブ: 資産構成の大きさを四角形のタイルサイズで視覚的に確認できる。セクター分析タブ: 「景気敏感株」「ディフェンシブ株」などの景気セクター分類をグラフ化。配当ソースリスト:グラフの下に、銘柄ごとの「年間配当予定額」と「個別利回り」を金額の大きい順にリスト表示。

------------------------------
##  月別配当グラフ画面（収入スケジュール）月ごとの配当金（分配金）の入金推移を棒グラフで表示し、年金化の進捗を確認する画面です。グラフエリア:1月〜12月までの12ヶ月分の「月別配当金」を並べた棒グラフ（縦棒）。日本株と米国株、投資信託を色分けした「積層型棒グラフ」にする。詳細リストエリア:グラフで選択した月、または直近の月に「どの銘柄から」「いくら」入金されるかのスケジュールをリスト表示。表示項目：確定月/支払月、銘柄名、予想配当額。

------------------------------
## 4️⃣ 銘柄追加・編集画面（入力モーダル）口座連携をしないため、ユーザーが迷わず1分で入力完了できるシンプルなフォーム画面です。入力項目:銘柄検索/コード入力: 日本株の4桁コード、または米国株のティッカー、投資信託名を入力。保有株数: 数量を数値入力。取得単価（任意）:損益計算用の購入単価を入力。口座種別選択（ラジオボタン/チップ）: 「新NISA（成長）」「新NISA（つみたて）」「特定口座/一般」高度な編集（アコーディオン等で隠す）:配当情報のカスタマイズ: 自動取得された配当金・確定月・回数を手動で上書き編集できる機能（手動編集時は [編] マークを付与）。株主優待相当額: 優待の価値を金額換算して手動入力し、配当利回りに加算できる入力欄。目標利回り設定: 「目標利回り（％）」を設定し、株価下落等でその利回りに達した際に通知する設定。メモ欄: 自由なテキスト入力欄。

##  設定・その他画面アプリの設定やデータの管理を行う画面です。アカウント・プラン:「プレミアム会員（月額280円）」へのアップグレード導線。データ管理（バックアップ機能）:「CSVインポート」：証券会社（SBI、楽天、マネックス、松井）から出力したCSVファイルを読み込んで一括登録するボタン。「クラウドバックアップ」：iCloudまたはGoogle Driveへのデータ保存・復元スイッチ。表示カスタマイズ:利回りの基準切り替え（評価額基準 vs 取得額基準）円グラフの「その他」にまとめる閾値（％）の手動調整スライダー（プレミアム用機能）

text# 🔖 アプリ画面開発指示書：配当管理アプリ（Flutter版）

あなたは優秀なモバイルUI/UXデザイナーおよびFlutterエンジニアです。
手動で銘柄を登録して配当金を可視化する「配当管理アプリ」を開発します。
パッケージは `lucide_icons` と `fl_chart` を導入済みです。

見た目の分かりやすさと洗練されたモダンな美しさを最優先し、以下の「デザインシステムおよび推奨ツール表」の基準を厳格に守って実装してください。

---

## 🛠️ デザインシステムおよび推奨ツール基準

画面を構築する際は、以下のFlutter推奨ツールを必ず使用し、ダッシュボード風の綺麗な見た目に仕上げてください。

| 重視したい見た目要素 | スマホアプリ（Flutter）での実装基準 |
| :--- | :--- |
| アプリ全体の雰囲気 | Material 3 を有効化（Google基準の分かりやすいモダンUI） |
| 資産額などのカード | Container / Card を使用（標準で綺麗な影や角丸、パディングを作る） |
| 配当金の円グラフ | fl_chart パッケージを使用（スマホ画面でタッチ操作しやすい直感的なグラフ） |
| アイコン（株・設定など） | lucide_icons（シンプルで視覚的に分かりやすいアイコン） |

---

## 🏗️ 共通仕様
* **カラーテーマ:** 信頼感のあるネイビー（または深みのあるエメラルドグリーン）を基調とし、ライトモード/ダークモード双方で美しく映える配色。
* **損益カラー:** プラス損益（緑〜青系）、マイナス損益（赤系）を明確に色分け。
* **ナビゲーション:** 画面下部に常駐する「ボトムナビゲーションバー（BottomNavigationBar）」を採用。
  - タブ構成：①資産管理 / ②年間配当 / ③月別グラフ / ④設定
  - 現在は「資産管理」タブのみ中身を実装し、他のタブは選択時に仮のテキストを表示させてください。

---

## 📱 今回実装する画面の詳細要件

資産管理画面（メインコンテンツ）

口座連携をしないため、ユーザーが手動登録したデータをダッシュボード風に美しく見せる画面です。

* **ヘッダーエリア（総資産サマリー）:**
  - `Card` または `Container` を使い、適度な影（Elevation）と角丸を持たせた美しいカード内に配置。
  - 「総資産評価額」を大きな太字で強調表示（例：¥3,500,000）。
  - 「トータル含み損益」を視覚的に目立つ角丸のバッジ（例：+¥450,000 / +14.7%）で表現。
* **フィルター・ソートエリア:**
  - 市場切り替え：「すべて」「日本株」「米国株」「投資信託」をスムーズに切り替えるチップ型（ChoiceChip）またはセグメント化されたコントロール。
* **銘柄リスト（スクロールエリア）:**
  - `ListView` を使用し、各銘柄を立体感のあるきれいなカード型（Card）でリスト表示。
  - 以下の3つのダミーデータを初期状態で綺麗にレイアウトしてください：
    1. トヨタ自動車 (7203) / 保有: 100株 / 評価額: ¥260,000 / 損益: +¥15,000 / 投資枠:「新NISA 成長枠」
    2. Apple (AAPL) / 保有: 10株 / 評価額: ¥340,000 / 損益: +¥42,000 / 投資枠:「特定口座」
    3. eMAXIS Slim 全世界株式 / 保有: 50,000口 / 評価額: ¥120,000 / 損益: -¥2,300 / 投資枠:「新NISA つみたて枠」
  - ※投資枠（新NISAなど）は小さなカラーバッジにして視覚的に分類してください。
* **フローティングアクションボタン（FAB）:**
  - 画面右下に、銘柄を追加するための洗練された丸い「＋」ボタンを配置。
