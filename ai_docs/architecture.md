# Architecture

## Runtime and storage

- The current app source is `kurogane-dividend/`; Android builds come from `kurogane-dividend/android/`.
- The Cloudflare Worker API is in `data/irbank/cloudflare/src/index.js` and uses D1 for operational records and R2 bucket `diview-market-data` for market snapshots.
- The Worker binds R2 as `MARKET_DATA`. R2 public URLs remain disabled; selected objects are served by explicit Worker routes.

## Japanese market data

- The listed-security data source is yfinance. J-Quants v2 supplies the eligible security-code universe; XTKS calendar sessions gate the scheduled run at 21:00 JST. The v2 collector and Worker changes are in the repository, but the first v2 R2 publication and production Worker deployment are still pending. Production currently serves the legacy API behavior; its monthly-price route was hotfixed to return the already split-adjusted stored close unchanged.
- New objects use `market/yfinance/v2/`: current profile and quote, year-partitioned dividends and splits, 13 months of monthly closes, 10 years of monthly-price archive, and app-required annual financial inputs. Dividend charts sum yfinance 1.7.0 repaired daily events by calendar year and assume returned dividend amounts are already split-adjusted; neither the collector nor Worker reapplies split ratios. SciPy 1.18.1 and scikit-learn 1.9.1 are pinned for the repair path. Unused legacy yfinance fields are gzip archived for 10 years after v2 read-back.
- The J-Quants master product category is retained so equities, ETFs, and REITs remain distinguishable; industry labels continue to come from the Android asset master. The collector sets Yahoo locale to `ja-JP`/`JP` and prefers Japanese `shortName`, Japanese `longName`, then an English name.
- The workflow in `.github/workflows/yfinance-r2.yml` runs the v2 job on weekdays and gates it with the XTKS calendar. It records per-security failures and makes at most four attempts per session, with 15-minute, 1-hour, and 4-hour backoffs.
- Repository Worker search results read `catalog/current.json`, which contains price and calculated yield; detail requests read that symbol's `profile.json` and `current.json`. The API excludes symbols without a published profile and completed close. Dividend-month, monthly-price, and `/api/v1/share-split-history` APIs read v2 objects only; the split-history route returns dated split ratios and the recorded fetch status for the requested period. Financial-data keeps legacy fallback for non-dividend financial and valuation fields, while its dividend history comes only from yfinance v2 events; before the first v2 publication it reports `not_fetched` instead of treating IRBANK adjusted DPS as Yahoo event data. Calculated XTKS rights-date data is stored at `market/yfinance/v2/derived/rights_dates/current.json`. `/api/v1/live-quotes` serves completed catalog data only; it does not call Yahoo Finance. The hourly Worker trigger no longer enqueues Yahoo live-price collection, and any messages left in the retired quote queue are acknowledged without fetching prices.
- Android search suggestions use quote fields from `/api/v1/security-search` and fill missing price/yield fields from the published R2 `/api/v1/search-catalog`. The in-memory catalog quote index is cached for five minutes. Neither path requests live Yahoo prices.
- Android Stock Detail accepts current dividend values only from the yfinance v2 current payload or its catalog fields; it calculates yield from that DPS and the selected close, showing `0.00%` when DPS is unavailable. The DPS field itself shows `未取得` when its status is unknown, while confirmed no-dividend remains zero. DPS-dependent comparisons, portfolio dividend concentration, reduction impact, expected receipts, combined yield, and reinvestment projections are suppressed or marked unavailable until DPS is known. Legacy fiscal-year DPS, calendar-year event totals, and standalone yield values are not substituted for current DPS. When security and catalog prices disagree, it selects the quote with the later `quote_date`. Production still serves legacy responses until the first v2 R2 publication and Worker deployment.
- Per-security yield displays use an explicit `dividend_status: no_dividend` signal for `0.00%（無配）`; missing or unknown yield data displays as `0.00%` per product requirement, while its underlying fetch status remains distinct. Android lets users edit up to eight completed calendar years of dividend and December month-end price values; each field shows whether it is at its initial value or user-edited. The editor lists R2 split and reverse-split events on the corresponding year, and saving a reset removes the encrypted device overrides so the fetched defaults return.
- Android monetary display formatting is centralized in `FinancialAmountDisplay.kt`: fractional stock prices and dividend amounts round to one decimal place, while whole amounts omit trailing decimals. `jpx_tick_eligibility.json` provides effective-dated JPX TOPIX500 equity membership and an official ETF list with trading units of 10 or more, including announced unit changes; for eligible Japanese securities priced at or below ¥1,000, `formatStockPriceDisplay` keeps one decimal even when the price is an integer. The bundled schedule is verified through 2027-02-28; JPX's liquidity-based tick-table change on 2027-03-01 requires replacing the schedule with the official per-security classification before that date.
- Android stores attempt time, last successful catalog time, JST success date, and fetch status per device. It refreshes no more than once per JST date and no sooner than 12 hours after the previous success; a failed refresh leaves local prices intact and can retry on a later app launch.
- The J-Quants adjusted-daily-quotes snapshot below is a separate historical debug endpoint. The Android market-data flow does not use it as a quote source.

## J-Quants adjusted daily quotes

- The original snapshot is stored at `debug/jquants/v1/daily_quotes.csv`.
- The public subset is stored at `debug/jquants/v1/adjusted_daily_quotes.csv` with columns `Date,Code,AdjFactor,AdjO,AdjH,AdjL,AdjC,AdjVo`.
- `GET` and `HEAD /api/v1/jquants/daily-quotes` stream the subset from R2; single byte-range requests are supported and limited to five requests per IP per minute.
- This is a static snapshot for 2024-07-22 through 2026-07-17. No refresh job is configured.
