Kurogane利用規約

配当蓄財と資産可視化シミュレーター規約

2025年改訂版

本規約は、合同会社Kurogane Labs（以下「当社」）が提供するポートフォリオ分析アプリ「Kurogane Dividend」の利用条件を定めるものです。

第1条（総則・本サービスの目的）

管理ツール expand_more

本アプリは、ユーザー自身が手動入力した保有銘柄、取得価格、保有株数に基づき、年間想定配当額、税引後キャッシュフロー、および受取月カレンダーを試算・可視化する「個人向け資産シミュレーションツール」です。

check_circle

証券口座の自動スクレイピング連携を行わず、ユーザーが主体的に配当構成を俯瞰・把握することを主眼としています。

第2条（投資助言に関する免責事項）

重要確認事項 expand_more

1. 当社は、金融商品取引法に基づく「金融商品取引業者（投資助言・代理業等）」ではありません。本アプリ内で表示される利回り、配当支払予定月、過去実績増配率は参考指標であり、特定の有価証券の売買推奨や投資助言を行うものではありません。

2. 配当金は企業の財務状況や市場動向により減配・無配となる場合があります。試算結果および税計算の完全性・正確性を保証するものではなく、いかなる投資判断の損失についても当社は責任を負いません。

第3条（利用環境およびローカルデータ管理）

非保持化

本アプリは、証券会社のログインID・取引パスワードを一切取得・保管・要求いたしません。

入力された資産データはユーザー所持端末の安全な領域（サンドボックス）内に暗号化保存されます。端末紛失やOS破損によるデータ消失に備え、必要に応じてエクスポート機能によるバックアップをお客様ご自身の責任で行うものとします。

第4条（知的財産権および禁止事項）

コンプライアンス

本アプリ内のUIデザイン、グラフィック、アルゴリズム、株価参照データベースの著作権は当社または正当な権利者に帰属します。リバースエンジニアリング、不正クローリング、複製行為は固く禁止いたします。

4. セキュリティ管理体制（SQLiteローカル暗号化）

ポートフォリオデータは、端末固有のセキュアキーストア（iOS Keychain / Android Keystore）から導出されたマスターキーにより、ローカルデータベース（SQLite）レベルで暗号化されています。端末が脱獄（Jailbreak）されていない限り、他のアプリケーションからの不正アクセスから強固に隔離保護されます。
