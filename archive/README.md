# Archived material

This directory holds superseded application projects and historical UI captures. The current design and implementation live only in `../kurogane-dividend/`.

- `legacy-projects/` — old Compose, React, Flutter, HTML, and image based proposals, including former `DiviewApp/` and `dividend/` copies. Do not build from them or reuse their designs.
- `legacy-flutter-scaffold/` — the old Flutter starter files formerly located at the workspace root. Not the current app.
- `visual-qa-captures/` — screenshots and UI inspection output from previous work. These are historical artifacts, not design references.

The contents are retained for traceability and are not deleted.
